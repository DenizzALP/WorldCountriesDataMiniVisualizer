# World Countries Data Mini Visualizer

This is a simple yet effective web project focused on **data visualization** using bar charts. Users can view global statistics by clicking on either "Population" or "Languages" to see the top 10 most populated countries or the most spoken languages in the world.

## Features

-  Visualizes country population and language frequency with dynamic bar charts
-  Simple, interactive interface
-  Focus on **data understanding** through visuals

## How It Works

- Click on the **Population** button to view the top 10 countries by population
- Click on the **Languages** button to see the top 10 most spoken languages
- The chart updates instantly to reflect your selection

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure
```
.
├── index.html # Main HTML structure
├── style.css # Basic styling
├── script.js # Chart rendering logic
└── countries.js # Contains country data (JSON-like)
```

## Getting Started

1. Clone the repository or download the project files.
   - git clone https://github.com/DenizzALP/WorldCountriesDataMiniVisualizer.git
2. Open `index.html` in your browser.
3. Click the buttons and explore the visual data!
